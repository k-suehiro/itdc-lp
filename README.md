# itdc-lp

株式会社クレステックの製品・サービス向けランディングページ（LP）を管理するリポジトリです。  
各 HTML は単体で配信できる静的ページとして構成されています。

## odomasy LP のファイル整理（2026年6月）

odomasy の LP は **デモ依頼特化版** を本番採用とし、ファイル名を整理しました。

| 変更前 | 変更後 | 状態 |
|--------|--------|------|
| `odomasy2.html` | **`odomasy.html`** | **本番採用・今後ここを更新** |
| `odomasy.html` | `_archive/odomasy-v1.html` | 旧版（アーカイブ・使用しない） |

- 公開 URL は `odomasy.html` のまま利用できます（`itdc.html` などからのリンクも変更不要）。
- 旧版は参照用に `_archive/` に退避しています。本番では使用しません。

## HTML ファイル一覧

### 製品・サービス LP

| ファイル | 説明 | 備考 |
|----------|------|------|
| **`odomasy.html`** | odomasy（ドキュメント統合管理システム）の LP | 無料デモ依頼に特化したコンバージョン型。**メインの更新対象** |
| `itdc.html` | CRESTEC システム開発ソリューションのポータル LP | Arrow3・odomasy など製品への導線を含む |
| `about_itdc.html` | データ＆システムエンジニアリングのガイド | ITDC 領域の説明ページ |

### 社内・イベント向け

| ファイル | 説明 | 備考 |
|----------|------|------|
| `arrow3.html` | AI 戦略および研究開発ガイドライン | 社内向けガイドライン |
| `gm2026.html` | 2026 グローバルミーティング プログラム | 編集後は `scripts/deploy-gm2026.ps1` で GAS へデプロイ |
| `odomasy-select.html` | odomasy LP 閲覧ポータル（社内プレビュー用） | GAS 連携で LP バージョンを選択して表示 |

### アーカイブ

| ファイル | 説明 | 備考 |
|----------|------|------|
| `_archive/odomasy-v1.html` | odomasy LP 旧版（標準・カタログ型） | **不採用**。機能詳細を LP 上に網羅した旧デザイン |

### GAS 配信用（同期コピー）

| ファイル | 説明 | 備考 |
|----------|------|------|
| `gas/gm2026.html` | `gm2026.html` のデプロイ用コピー | ルートの `gm2026.html` と内容を揃える |

## その他のディレクトリ

```
itdc-lp/
├── css/                  … LP 共通スタイル（コーポレート導線など）
├── js/                   … LP 共通スクリプト（コーポレート導線など）
├── odomasy-images/       … odomasy LP 用画像・アセット
├── gas/                  … Google Apps Script デプロイ用
├── scripts/              … デプロイスクリプト
├── _archive/             … 使用しない旧ファイルの保管
└── LP_CORPORATE_LINKS.md … コーポレートサイト導線の実装ガイド
```

## 開発メモ

- **odomasy を更新するとき**は `odomasy.html` のみを編集してください。
- コーポレートサイトへの導線を追加・変更する場合は `LP_CORPORATE_LINKS.md` を参照してください。
- `gm2026.html` を変更した場合は `.cursor/rules/gm2026-deploy.mdc` に従いデプロイしてください。
